## 🧑‍🤝‍🧑 求职者端（找兼职）

- 微信一键登录、实名核验，简化资料，不用长篇简历，填：可上岗时段、技能、就近范围
- LBS 同城附近兼职、地图找岗，精准筛选：距离、日结 / 周结、小时工、周末兼职、夜班、学生兼职
- 岗位分类：商超促销、会展协助、家教、家政、分拣装卸、传单、外卖帮工、临时安保
- 一键报名、抢单模式、岗位收藏、报名记录
- 隐私拨号、内置 IM 聊天（文字图片），保护手机号
- 上岗定位打卡、工时记录、完工确认、薪资账单、钱包、提现、双向评价、黑名单
- 学生兼职专区、短期单日任务专区

## 🏪 用工商家端（发兼职）

- 个人商家 / 小店 / 活动公司均可入驻，资质审核（营业执照 / 实名）
- 快速发布兼职任务：工作地点、时段、时薪、人数、结算方式、是否包餐、工作要求
- 报名列表管理：审核报名、联系候选人、上岗确认、完工验收
- 岗位管理：上架、下架、刷新、置顶、加急
- 可以发布单次短期任务，不用长期招聘
- 评价求职者，标记不靠谱人员

## ✨ 核心特色（兼职零工版重点）

1. **轻量化**：不强制复杂简历，重点看【时间、地点、时薪、结算】，学生、宝妈、临时打工人上手快
2. **同城优先 LBS**，适合做县城、市区本地化兼职平台，社群裂变传播

4. **结算灵活**：日结为主，支持平台担保托管薪资，减少跑单欠薪纠纷
5. **H5 链接引流**：微信群、朋友圈直接转发岗位链接，不用引导扫码进小程序
